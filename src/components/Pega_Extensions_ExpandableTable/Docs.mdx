# Expandable Table

Read-only expandable list as a table, accordion list, or category tabs; boolean columns act as select-all for nested checkboxes

- **Component key:** `Pega_Extensions_ExpandableTable`
- **Type:** Template
- **Subtype:** FORM
- **Catalogue version:** 5.0.6

## Designer configuration

The `config.json` file in this folder contains the gallery property-panel metadata and defaults for this component. Keep its `name`, `componentKey`, and the folder name synchronized.

This entry point is registered with Pega's `withConfiguration` wrapper and delegates shared field, widget, or template behavior to the POC runtime adapter.
